# 校园网直连

盐城工学院 **YIT-WIFI** 一键直连。双击运行，点一下就连上 —— 不用再开浏览器等门户跳转、输账号密码。

> 个人自用工具，与学校官方无关。门户改版就可能失效。

## 怎么用

1. 双击运行（跑源码：`python src/yit_connect.py`，需 Python 3.8+）
2. 首次填一次账号密码 → 点「直连并保存」
3. 之后每次双击，就一个「直连」按钮

已经联网时打开，会显示「当前已经联网 ✓」，只给「切换账号」和「关闭后台」两个按钮。

**打包成单文件 exe**：`python build.py`（约 11 MB，会顺手复制到桌面；仓库里不放二进制）

## 特点

- **账号密码加密保存** —— 用 Windows DPAPI，绑定当前 Windows 账户，换台电脑解不开
- **自动腾名额** —— 账号最多 2 台设备同时在线，满了会自动去自助服务踢掉**你自己名下**的另一台，全程不用验证码、不用你参与
- **零依赖** —— 只用 Python 标准库，clone 下来直接跑
- **不碰系统** —— 不写注册表、不加计划任务、不改系统代理、不设防火墙规则

## 说明

- 只适用**盐城工学院 YIT-WIFI**。其他学校想用，得照着 `MANIFEST.md` 里的协议记录自己改
- 只访问校园网自己的 `10.10.10.5` / `10.10.10.8`，**不向任何第三方发送数据**；运行日志不记密码
- 只支持 Windows，测过 Windows 11
- 卸载：`python uninstall.py --dry-run`（先预览会删什么，不动手）
